# COVID-19 Tracking Dashboard (January–July 2020)

An interactive Tableau dashboard exploring COVID-19 case, death, and recovery data by country between January and July 2020, sourced from World Health Organization data.

## Key Features

- **Interactive world map** — select any country to filter all metrics and view country-specific detail
- **KPI tiles** — Total Cases, Fatality Rate, Recovery Rate, and Active Cases for the selected country
- **Cases and deaths over time** — a trend line tracking cumulative case and death growth across the tracked period
- **Peak case/death tracking** — identifies each country's single highest day of new cases and new deaths, with the corresponding date

## Overview

This project visualizes country-level COVID-19 spread and severity during the first several months of the pandemic. Users can select any country on the map to drill into that country's specific case totals, fatality and recovery rates, and outbreak trajectory over time, or view aggregated global metrics by default.

## Tools Used

- Tableau

## Data Source

Dataset sourced from [Kaggle: COVID-19 Dataset](https://www.kaggle.com/datasets/imdevskp/corona-virus-report) by imdevskp, compiled from WHO, Johns Hopkins CSSE, and other public health sources, covering January–July 2020.
